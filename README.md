# Project: Picky ! ! 🍴

### Goal: Create a full-stack Express app that has CRUD functionality

## Result: An event-sharing app that allows you to invite friends to eat! - They can tell you their dietary restrictions. (: 

* An event sharing / inviting app
* Allows people to see shared dietary restrictions for a food outing
* Each event creates a unique id that can be shared with friends - no sign-up required!.
* Events can be updated or deleted


## How to Use

1. Check out the [Picky Eats app here](https://picky-v3j9.onrender.com/).
2. Create your Event
    * Name your event
    * Select the date & time
    * Select what kind of food outing this will be from the drop-down!
  
3. Submit your Event
4. Browse all events submitted on the Events page
5. You can edit or delete events!
